# Podcast

Audio-forward site theme for episode archives, guest pages, clips, and supporting show notes.

Package: `@phantasy/theme-podcast`
Type: `theme`
Workspace: `site`
Extension kind: `presentation`
Repo: https://github.com/phantasy-bot/theme-podcast
Phase: `source-extracted`

## Install

```bash
phantasy extensions install theme podcast
```

## Status

This repo is seeded from the Phantasy monorepo and is now intended to keep converging toward independent maintenance.
